HTB Arctic: ColdFusion traversal to admin to SYSTEM

retired-machineeasy

Arctic is a retired HackTheBox easy Windows machine centered on Adobe ColdFusion 8. Synopsis: directory traversal (CVE-2010-2861) leaks the admin hash, the admin console schedules a CFM shell, and the service is SYSTEM.

$ Enumeration — fingerprint the middleware

# bash: spot ColdFusion 8
nmap -sC -sV -oN arctic.nmap 10.10.10.11
gobuster dir -u http://10.10.10.11:8500 -w common.txt   # -> /CFIDE/administrator/

HTTP on Server 2008 with /CFIDE/ paths all over the site. The version plus the /CFIDE/administrator/ surface is the whole recon story: ColdFusion 8 means CVE-2010-2861. Fingerprint the app, not just the server.

$ Foothold — traversal to admin hash

# bash: read password.properties via traversal
# administrator login vulnerable to .../ traversal (CVE-2010-2861):
curl "http://10.10.10.11:8500/CFIDE/administrator/enter.cfm?locale=../../../../../../../../../../ColdFusion8/lib/password.properties%00en"
# crack the hash, log into the CF admin console

The traversal reads password.properties, exposing the admin password hash. Crack it, log into the ColdFusion administrator console, and use scheduled tasks to execute a malicious CFM file — a webshell with the full ColdFusion API behind it. Start with a simple command-execution tag to prove code exec, then upgrade to a full shell.

$ Flags — service is SYSTEM

The ColdFusion service runs as SYSTEM, so the scheduled CFM shell lands at the top of the privilege ladder and both flags fall immediately. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

Attacking the IIS layer (the web server is fine — the middleware is the vulnerability) and writing a complex CFM payload first.

$ Remediation notes

Retire ColdFusion 8, run application services as dedicated low-privilege accounts, and lock admin consoles behind network controls. Written by Lucky Thandel.
